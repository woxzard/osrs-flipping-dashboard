# OSRS overnight flipping dashboard

A phone-first page, refreshed every hour, that shows the best overnight flips in Old School RuneScape for the cash I have.

Prices come from the [OSRS Wiki real-time prices API](https://oldschool.runescape.wiki/w/RuneScape:Real-time_Prices). Suggestions are odds based on the last 14 nights, not promises.
